# Révisions L1 LEA

Application personnelle de révision (L1 LEA anglais-arabe) : fiches par chapitre, quiz variés, répétition espacée, examens blancs, planning et statistiques.

- Site statique (HTML, CSS, JavaScript), sans serveur.
- Installable sur téléphone (« Ajouter à l'écran d'accueil »), fonctionne hors ligne après la première visite.
- La progression est enregistrée dans le navigateur de l'appareil (localStorage).

Contenu : résumés et exercices rédigés à partir des fiches de révision personnelles.
